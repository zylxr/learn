XGBoost底层实现了GBDT算法，并对GBDT算法做了一系列优化：

对目标函数进行了泰勒展示的二阶展开，可以更加高效拟合误差。
提出了一种估计分裂点的算法加速CART树的构建过程，同时可以处理稀疏数据。
提出了一种树的并行策略加速迭代。
为模型的分布式算法进行了底层优化。
XGBoost是基于CART树的集成模型，它的思想是串联多个决策树模型共同进行决策。



那么如何串联呢？XGBoost采用迭代预测误差的方法串联。
举个通俗的例子，我们现在需要预测一辆车价值3000元。我们构建决策树1训练后预测为2600元，我们发现有400元的误差，
那么决策树2的训练目标为400元，但决策树2的预测结果为350元，还存在50元的误差就交给第三棵树……以此类推，每一颗树用来估计之前所有树的误差，最后所有树预测结果的求和就是最终预测结果！

XGBoost的基模型是CART回归树，它有两个特点：（1）CART树，是一颗二叉树。（2）回归树，最后拟合结果是连续值。



ART，全称为分类与回归树（Classification and Regression Trees），是一种决策树算法，由Leo Breiman、Jerome Friedman、Richard Olshen和Charles Stone在1984年提出。
CART树既可以用于分类问题也可以用于回归问题，其通过递归地分割数据集来构建二叉树。

CART树的特点：
二叉树结构：与ID3、C4.5等多分支决策树不同，CART总是采用二分法对节点进行分裂。
适用于分类和回归：对于分类问题，使用基尼系数或分类误差来决定如何分裂；对于回归问题，则使用平方误差最小化原则。
剪枝策略：为了避免过拟合，CART采用了成本复杂度剪枝方法（cost complexity pruning），也叫做后剪枝，通过一个叫做“复杂度参数”的变量来平衡树的大小和它的训练误差。
处理缺失值：虽然原始的CART算法没有直接处理缺失值的方法，但实践中可以通过代理分裂等方式来处理缺失值问题。
分裂准则：
分类树：使用Gini指数作为分裂准则。Gini指数衡量的是从数据集中随机抽取两个样本，其类别不一致的可能性。Gini指数越小，说明数据纯度越高。
回归树：选择使平方误差最小化的特征及其阈值来进行分裂。平方误差反映了预测值与实际值之间的差异程度。


GBDT，全称为Gradient Boosting Decision Tree（梯度提升决策树），是一种集成学习方法，主要用于回归和分类问题。它通过迭代地训练一系列决策树模型来构建一个强学习器，每棵树都在尝试修正前一棵树的错误。

GBDT的核心思想
迭代训练：GBDT是基于Boosting思想的一种算法，其通过多轮迭代，每一轮生成一棵决策树。新树都是在试图减少前几轮树的误差。
损失函数：每一轮训练都旨在最小化某个定义好的损失函数（比如平方损失、绝对损失或对数损失等）。与AdaBoost不同，GBDT通过对损失函数进行梯度下降的方式来确定每棵树的优化方向。
残差拟合：在每次迭代中，GBDT会计算当前模型对训练数据的残差（即真实值与预测值之间的差异），然后训练一个新的决策树来拟合这个残差。这样，后续的树就能专注于纠正之前树的错误。
正则化：为了防止过拟合，GBDT可以通过限制树的深度、叶子节点的最小样本数、学习率等参数来进行正则化。
GBDT的关键步骤
初始化：通常从一个常数值开始，这个值通常是目标变量的平均值（对于回归问题）或者对数几率的平均值（对于二分类问题）。
迭代过程：
计算伪残差：基于当前模型的预测结果和实际目标值，计算出每个样本的伪残差。
拟合新树：使用这些伪残差作为新的目标值来训练一颗新的决策树。
更新模型：将新树的结果按照一定的学习率加到现有模型上，得到更新后的模型。
终止条件：达到预定的树的数量或者模型性能不再显著提升时停止。


决策树是一种监督学习方法，既可以用于分类问题（分类树），也可以用于回归问题（回归树）。它通过递归地将数据集分割成不同的子集，从而形成一个树形结构。每个内部节点表示对某个属性的测试，每个分支代表一个测试输出，而每个叶节点代表一种类别或一个连续值预测。

决策树的基本概念
根节点（Root Node）：树的起始点，包含整个数据集。
内部节点（Internal Node）：代表数据集的一个特征，并且根据该特征的不同取值将数据划分为多个子集。
叶节点（Leaf Node）：也称终端节点，表示决策结果，在分类问题中是类别标签，在回归问题中是具体的数值。
分支/边（Branch/Edge）：连接节点的线段，表示从一个节点到另一个节点的路径。
构建决策树的过程
选择最佳特征进行分裂：在每个步骤中，算法会选择当前最好的特征来分割数据。对于分类问题，通常使用基尼不纯度、信息增益或信息增益率等指标来评估；对于回归问题，则可能采用平方误差减少等标准。
递归划分：基于选定的特征，将数据集分成几个子集，并对每个子集重复上述过程，直到满足某些停止条件，如达到最大深度、节点中的样本数小于阈值等。
剪枝（Pruning）：为了避免过拟合，可以通过剪枝来简化决策树。常见的策略包括预剪枝（提前终止树的增长）和后剪枝（先构建完整的树，然后移除不必要的分支）。
